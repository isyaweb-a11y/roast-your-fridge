A single line roasting my fridge, for the [make.fun](https://make.fun) bounty
**One Line, One Laugh: Roast Your Fridge**.

## The line

> My fridge hums all night like it's rehearsing for a concert, then lets the milk go off before the encore.

105 characters. The fridge gets the spotlight it never asked for: it hums
all night like a performer warming up, and still can't keep the milk alive
long enough for the show.

## How it works

`main.py` (Python 3, standard library only) validates the line — 1–200
characters, not blank, and it must actually roast a fridge or a phone —
then writes it to `/output/entry.txt`. Run it with `python3 main.py`.
